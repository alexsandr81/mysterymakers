# MysteryMakers — интернет-магазин на Laravel

Новый магазин «с нуля» вместо старого эксперимента. Светлая тема с тёплой древесной палитрой,
два языка (украинский / русский), цены в гривнах.

## Что уже есть

**Витрина:** главная, каталог с категориями и подкатегориями, фильтр по цене и наличию, сортировка,
пагинация, поиск (название на обоих языках + артикул), карточка товара с галереей, корзина,
оформление заказа (гость или пользователь), регистрация/вход, личный кабинет с историей заказов,
переключатель языка UK/RU.

**Админка** (`/admin`, только для `is_admin = 1`): дашборд, заказы со сменой статуса,
товары (создание/редактирование/удаление, до 5 фото, скидка через «старую цену», характеристики), категории,
**страницы** (доставка, контакты, о нас — любые свои), **баннеры** на главной, **характеристики** товаров.

**Настройки:** название магазина и подпись (шапка, подвал, письма), несколько телефонов, email, адрес.
**Страницы с разделами:** кроме основного текста можно добавлять разделы («График работы», «Email» и т. п.) — каждый показывается отдельным блоком с жирным заголовком.
**Фото:** при загрузке товаров и баннеров автоматически уменьшаются (до 1600/1920 px) и пережимаются в WebP/JPEG (нужно расширение PHP GD — в Laragon оно включено).

**Пользователи:** список с поиском, правка данных, смена пароля, выдача/снятие прав администратора, удаление (заказы сохраняются).
**Избранное:** кнопка ♡ на карточке и странице товара (для вошедших), список в личном кабинете.
**Номера заказов:** только цифры (1001, 1002, …); у позиций заказа есть фото.

**Страницы:** создаются в админке, открываются по адресу `/page/<адрес>`, ссылки автоматически попадают в подвал сайта.
**Баннеры:** слайдер на главной с автопрокруткой; без баннеров показывается обычная шапка.
**Характеристики:** задаёте «Материал», «Цвет», «Размер»… и их варианты, выбираете в карточке товара;
на странице товара они показываются таблицей, а в каталоге появляются фильтры (показываются только те варианты,
которые есть у товаров текущей категории).

**Что исправлено по сравнению со старым проектом:** остатки списываются при заказе (в транзакции,
с блокировкой строк), при отмене заказа возвращаются; цена и сумма считаются в одном месте;
все формы защищены CSRF, удаление только через POST/DELETE; вход через стандартную
авторизацию Laravel; пароли только в `.env`, в git их нет.

## Установка (локально)

### 1. Один раз поставить инструменты (Windows)
Самый простой путь — **[Laragon](https://laragon.org/download/) (Full)**: в нём уже есть PHP, Composer и MySQL.
Установите, запустите, откройте его терминал.
(Нужны PHP 8.2+ и Composer. База для локальной работы — SQLite, отдельный MySQL не нужен.)

### 2. Развернуть проект
В терминале, в папке с этим проектом:

```
setup.bat          (Windows)
./setup.sh         (Linux / macOS)
```

Скрипт скачает чистый Laravel в папку `shop`, положит туда файлы магазина, создаст базу и демо-товары.

### 3. Запустить
```
cd shop
php artisan serve
```
Сайт: http://127.0.0.1:8000 · Админка: http://127.0.0.1:8000/admin

Первый вход: `admin@mysterymakers.local` / `admin12345` — **сразу смените пароль**
(пока через `php artisan tinker`, форма смены пароля — в планах).

## Доставка и оплата

Способы доставки: **Новая Почта** (город и отделение/почтомат) и **Укрпошта** (город и индекс отделения).
Оплата: пока только **наложенный платёж** (оплата при получении). Оплата картой будет добавлена позже.

Чтобы клиент выбирал город и отделение Новой Почты из списка, нужен бесплатный API-ключ:
1. Войдите в https://business.novaposhta.ua/ (нужен договор или регистрация как отправитель).
2. **Налаштування → Безпека → Ключі API → Створити**.
3. Впишите ключ в `.env`: `NOVAPOSHTA_API_KEY=ваш_ключ`, затем `php artisan config:clear`.

Без ключа на форме показываются обычные текстовые поля «Город» и «Отделение».

## Почта (письма клиентам)

Сайт отправляет письма: подтверждение заказа, смена статуса заказа, ссылка для сброса пароля.
По умолчанию письма пишутся в `storage/logs/laravel.log` (`MAIL_MAILER=log`). Чтобы отправлять настоящие письма,
впишите в `.env` данные SMTP (пример для Gmail с «паролем приложения»):

```
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=ваш@gmail.com
MAIL_PASSWORD=пароль_приложения_без_пробелов
MAIL_FROM_ADDRESS=ваш@gmail.com
MAIL_FROM_NAME="MysteryMakers"
```

Затем `php artisan config:clear`. Если письмо не уходит, заказ всё равно оформляется, а причина пишется в `laravel.log`.
На хостинге используйте SMTP хостинга или сервис рассылок (Brevo, Mailgun, Resend и т. п.).
Пароль почты никогда не коммитьте в репозиторий.

## Вход через Google

Кнопка «Войти через Google» появляется на страницах входа и регистрации, только когда в `.env` заданы ключи.

1. Откройте https://console.cloud.google.com/ → создайте проект → **APIs & Services → OAuth consent screen**
   (тип External, укажите название и свой email; пока приложение в режиме Testing, добавьте свой Gmail в «Test users»).
2. **Credentials → Create credentials → OAuth client ID → Web application**.
3. В **Authorized redirect URIs** добавьте (оба варианта, для локальной работы):
   `http://127.0.0.1:8000/auth/google/callback` и `http://localhost:8000/auth/google/callback`.
   На хостинге добавьте `https://ваш-домен/auth/google/callback`.
4. Скопируйте Client ID и Client secret в файл `.env` сайта:
   ```
   GOOGLE_CLIENT_ID=...apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=...
   ```
5. Выполните `php artisan config:clear` и перезапустите `php artisan serve`.

Если у человека уже есть аккаунт с тем же email, Google-вход привяжется к нему. Секрет никогда не коммитьте в репозиторий.

## Обновление уже установленного сайта

Когда в репозитории появились новые функции, а сайт у вас уже стоит (например, в `C:\laragon\www\shop`):

```
update.bat "C:\laragon\www\shop"
```

Скрипт скопирует новые файлы, применит миграции и добавит демо-страницы и характеристики.
Данные в базе (товары, заказы, пользователи, ваш пароль администратора) не затрагиваются.

## Как расширять

| Что нужно | Куда смотреть |
|---|---|
| Добавить товар / категорию | Админка → Товары / Категории |
| Текстовая страница (доставка, контакты…) | Админка → Страницы |
| Баннер на главной | Админка → Баннеры |
| Материал, цвет, размер и т. п. | Админка → Характеристики, затем выбрать в карточке товара |
| Страница со своей логикой | маршрут в `routes/web.php` + контроллер + `resources/views/...` с `@extends('layouts.app')` |
| Поменять цвета | переменные в начале `public/css/app.css` |
| Тексты интерфейса | `lang/uk/shop.php` и `lang/ru/shop.php` |
| Новое поле у товара | новая миграция (`php artisan make:migration`) + `app/Models/Product.php` + форма в админке |
| Новый способ доставки/оплаты | `Order::DELIVERY` / `Order::PAYMENT` и тексты в `lang/*/shop.php` |

Структура: `app/Models` — данные, `app/Http/Controllers` — логика страниц, `app/Services/Cart.php` — корзина,
`resources/views` — шаблоны, `database/migrations` — структура базы.

## Перенос на хостинг

1. Нужен хостинг с **PHP 8.2+** и MySQL (подойдёт почти любой, с SSH — проще всего).
2. Загрузить проект (папка `shop`), на сервере выполнить `composer install --no-dev --optimize-autoloader`.
3. Создать базу MySQL, в `.env` на сервере указать `DB_CONNECTION=mysql`, `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`,
   а также `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL=https://ваш-домен`.
4. `php artisan key:generate` (если ключа нет), `php artisan migrate --seed --force`, `php artisan storage:link`.
5. Корень сайта (document root) направить на папку `public`.
6. Сменить пароль администратора и удалить демо-товары.

## Дашборд, уведомления, SEO, резервные копии, тесты

- **Дашборд** (`/admin`): период 7/30/90 дней, выручка, число заказов, средний чек, график продаж по дням, топ товаров, статусы заказов, товары на исходе, последние заказы.
- **Уведомление о новом заказе:** при каждом заказе владельцу приходит письмо. Адрес задаётся в «⚙ Настройки» → «Email для уведомлений» (если пусто — используется Email магазина).
- **SEO:** `/sitemap.xml`, `robots.txt`, canonical и Open Graph, микроразметка товара (цена, наличие, рейтинг). После переноса на домен добавьте строку `Sitemap:` в `public/robots.txt`.
- **Резервная копия:** кнопка в админке («💾 Копии») или `php artisan shop:backup`. Нужно расширение PHP zip (Laragon → PHP → Extensions → zip) — база (SQLite) и фото в zip в `storage/backups` (хранится 10 последних, `--keep=N`). Файл `.env` в архив не входит.
- **Тесты:** `php artisan test` (папка `tests`).

## Накладные Новой Почты

1. В `.env` должен быть `NOVAPOSHTA_API_KEY`, в кабинете my.novaposhta.ua — контрагент-отправитель.
2. Админка → «📦 Новая Почта»: выберите контрагента и контактное лицо, телефон, город и отделение отправки, вес и описание груза.
3. В заказе Новой Почтой (город и отделение выбраны из списка) — кнопка «Создать накладную». При наложенном платеже сумма заказа ставится как обратная доставка.
4. Там же: печать PDF, обновление статуса посылки, удаление накладной.

Чтобы появились поля накладной в заказах, после обновления выполняется миграция (её делает `update.bat`).
