# MysteryMakers — интернет-магазин на Laravel

Новый магазин «с нуля» вместо старого эксперимента. Светлая тема с тёплой древесной палитрой,
два языка (украинский / русский), цены в гривнах.

## Что уже есть

**Витрина:** главная, каталог с категориями и подкатегориями, фильтр по цене и наличию, сортировка,
пагинация, поиск (название на обоих языках + артикул), карточка товара с галереей, корзина,
оформление заказа (гость или пользователь), регистрация/вход, личный кабинет с историей заказов,
переключатель языка UK/RU.

**Админка** (`/admin`, только для `is_admin = 1`): дашборд, заказы со сменой статуса,
товары (создание/редактирование/удаление, до 5 фото, скидка через «старую цену», характеристики), категории,
**страницы** (доставка, контакты, о нас — любые свои), **баннеры** на главной, **характеристики** товаров.

**Страницы:** создаются в админке, открываются по адресу `/page/<адрес>`, ссылки автоматически попадают в подвал сайта.
**Баннеры:** слайдер на главной с автопрокруткой; без баннеров показывается обычная шапка.
**Характеристики:** задаёте «Материал», «Цвет», «Размер»… и их варианты, выбираете в карточке товара;
на странице товара они показываются таблицей, а в каталоге появляются фильтры (показываются только те варианты,
которые есть у товаров текущей категории).

**Что исправлено по сравнению со старым проектом:** остатки списываются при заказе (в транзакции,
с блокировкой строк), при отмене заказа возвращаются; цена и сумма считаются в одном месте;
все формы защищены CSRF, удаление только через POST/DELETE; вход через стандартную
авторизацию Laravel; пароли только в `.env`, в git их нет.

## Установка (локально)

### 1. Один раз поставить инструменты (Windows)
Самый простой путь — **[Laragon](https://laragon.org/download/) (Full)**: в нём уже есть PHP, Composer и MySQL.
Установите, запустите, откройте его терминал.
(Нужны PHP 8.2+ и Composer. База для локальной работы — SQLite, отдельный MySQL не нужен.)

### 2. Развернуть проект
В терминале, в папке с этим проектом:

```
setup.bat          (Windows)
./setup.sh         (Linux / macOS)
```

Скрипт скачает чистый Laravel в папку `shop`, положит туда файлы магазина, создаст базу и демо-товары.

### 3. Запустить
```
cd shop
php artisan serve
```
Сайт: http://127.0.0.1:8000 · Админка: http://127.0.0.1:8000/admin

Первый вход: `admin@mysterymakers.local` / `admin12345` — **сразу смените пароль**
(пока через `php artisan tinker`, форма смены пароля — в планах).

## Обновление уже установленного сайта

Когда в репозитории появились новые функции, а сайт у вас уже стоит (например, в `C:\laragon\www\shop`):

```
update.bat "C:\laragon\www\shop"
```

Скрипт скопирует новые файлы, применит миграции и добавит демо-страницы и характеристики.
Данные в базе (товары, заказы, пользователи, ваш пароль администратора) не затрагиваются.

## Как расширять

| Что нужно | Куда смотреть |
|---|---|
| Добавить товар / категорию | Админка → Товары / Категории |
| Текстовая страница (доставка, контакты…) | Админка → Страницы |
| Баннер на главной | Админка → Баннеры |
| Материал, цвет, размер и т. п. | Админка → Характеристики, затем выбрать в карточке товара |
| Страница со своей логикой | маршрут в `routes/web.php` + контроллер + `resources/views/...` с `@extends('layouts.app')` |
| Поменять цвета | переменные в начале `public/css/app.css` |
| Тексты интерфейса | `lang/uk/shop.php` и `lang/ru/shop.php` |
| Новое поле у товара | новая миграция (`php artisan make:migration`) + `app/Models/Product.php` + форма в админке |
| Новый способ доставки/оплаты | `Order::DELIVERY` / `Order::PAYMENT` и тексты в `lang/*/shop.php` |

Структура: `app/Models` — данные, `app/Http/Controllers` — логика страниц, `app/Services/Cart.php` — корзина,
`resources/views` — шаблоны, `database/migrations` — структура базы.

## Перенос на хостинг

1. Нужен хостинг с **PHP 8.2+** и MySQL (подойдёт почти любой, с SSH — проще всего).
2. Загрузить проект (папка `shop`), на сервере выполнить `composer install --no-dev --optimize-autoloader`.
3. Создать базу MySQL, в `.env` на сервере указать `DB_CONNECTION=mysql`, `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`,
   а также `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL=https://ваш-домен`.
4. `php artisan key:generate` (если ключа нет), `php artisan migrate --seed --force`, `php artisan storage:link`.
5. Корень сайта (document root) направить на папку `public`.
6. Сменить пароль администратора и удалить демо-товары.
